# QFI Alumni & Students Association

Sito pubblico dell’associazione: [qfi-alumni.github.io](https://qfi-alumni.github.io/). Il progetto usa Jekyll e il tema Ruby [al-folio](https://github.com/alshedivat/al-folio), con un layout dedicato a QFI. GitHub Actions pubblica ogni aggiornamento di main su GitHub Pages dalla repository dell’organizzazione QFI.

Per avviare l’anteprima, usa Ruby 3.3, poi esegui **bundle install** e **bundle exec jekyll serve**.

Le pagine sono in _pages, la home è in index.html e il layout comune è in _layouts/qfi.html. La navigazione deriva dal campo nav_order di ciascuna pagina. Il PDF in Archivio è la newsletter originale dell’associazione. Pubblica qui soltanto materiali destinati alla diffusione pubblica.
